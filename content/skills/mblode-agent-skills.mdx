# mblode/agent-skills

`mblode/agent-skills` is an open-source Agent Skills collection focused on
shipping polished UI, typography, documentation, pull requests, and releases.
It installs as a pack through the skills CLI and exposes focused `SKILL.md`
workflows agents can load by name.

Homepage: [blode.co/agent-skills](https://blode.co/agent-skills)

## Install

```bash
npx skills add mblode/agent-skills -g --agent codex claude-code -y
```

## Included skills

The pack currently includes skills such as `ui-design`, `ui-verification`,
`typography-audit`, `ui-animation`, `docs-writing`, `readme-creator`,
`pr-reviewer`, `pr-creator`, `pr-babysitter`, `autoship`,
`product-design`, `seo`, and `agent-skills-creator`.

## When to use

- Auditing AI-generated UI for visual and interaction defects
- Enforcing typography and documentation quality before merge
- Driving PR review, creation, and release note workflows from an agent host
